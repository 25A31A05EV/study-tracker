# 📚 Study Tracker + Grade Predictor

A Streamlit web app to track daily study sessions and predict exam marks using Machine Learning (Linear Regression).

## Features
- Track study sessions (subject, hours, date, marks)
- Dashboard with key metrics (total hours, subjects, average per session)
- Subject-wise study hours chart
- Marks trend over time (line chart)
- Grade Predictor — trains a Linear Regression model on your own study data to predict marks based on hours studied
- Delete individual records or clear all records
- Export data as CSV

## Tech Stack
- Python
- Streamlit (web app framework)
- Pandas (data handling)
- scikit-learn (Linear Regression model)

## How to Run
\`\`\`bash
pip install streamlit pandas scikit-learn
streamlit run app.py
\`\`\`
